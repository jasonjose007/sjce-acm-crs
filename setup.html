SJCE ACM CRS Team Setup

🔧 One-Time Setup

Run this once to create all 5 team member accounts in Firebase. After this page is done, delete or don't deploy it.

⚠️ Make sure you've created your Firebase project and enabled Firestore and Email/Password Authentication before running setup.

Before you begin:

Go to console.firebase.google.com → Create Project → name it "sjce-acm-crs"
Build → Firestore Database → Create database → Start in test mode
Build → Authentication → Get Started → Email/Password → Enable
Project Settings (gear icon) → Your Apps → Add Web App → Copy the config object
Paste each config value below and click Initialize

✅ Setup Complete!

All 5 accounts created. Now paste the Firebase config into login.html, admin.html, and member.html where it says REPLACE_API_KEY etc. Then you can delete or unlist this page.
